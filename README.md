# mjai-behavior-analysis

**简体中文** | [English](README.en.md) | [日本語](README.ja.md)

用 [Mortal](https://github.com/Equim-chan/Mortal) 作为参照引擎，量化分析**人类麻将玩家的出牌一致性**，并研究其**失误结构**——失误率如何随局面的"明确程度"变化。

本项目只做测量与建模，不含任何操控游戏客户端、自动对局或绕过反作弊的实现。

## 主要发现

在 71 局高阶对局（10,585 个决策）上的测量结果：

| 发现 | 数值 |
|---|---|
| 人类一致率（与 AI 首选相同） | **80.4%**（局间 sd 3.67pp） |
| 失误率 | 19.62% |
| 失误中"近等价"占比（质量分 > 0.8） | **73.9%** |
| 失误中"深坑"占比（质量分 < 0.2） | 11.5% |

**1. 失误率是"决策明确程度"的强函数**

以最优与次优动作的 q 值差（gap）分桶：

| gap | 决策数 | 失误率 |
|---|---|---|
| 0 ~ 0.1（两可） | 423 | **56.7%** |
| 0.3 ~ 0.6 | 1,013 | 48.1% |
| 1.2 ~ 2.5 | 2,396 | 14.6% |
| 2.5 以上（明确） | 4,349 | **2.7%** |

**2. 一致率与段位几乎无关**

Tier 13 (81.6%)、Tier 9 (83.3%)、Tier 4 (80.1%)、Tier 3 (79.2%) 之间的差异远小于组内波动，统计上不显著。一致率衡量的是"打法有多接近参考 AI"，而不是棋力。

**3. 深坑几乎全部来自鸣牌判断**

弃牌决策的失误质量分集中在 0.78~0.99（都是"换一张差不多的牌"），而质量分 < 0.2 的深坑主要出现在吃/碰/杠的取舍上（鸣牌窗口偏离率 10.9%）。

**4. 失误近似独立，不成簇**

逐局失误序列的 lag-1 自相关为 +0.021（i.i.d. 期望 −0.007），说明人类的失误在局内接近独立事件。

**5. 局长度对一致率无影响**

决策数与一致率的相关系数 r = +0.034。

## 方法

```
检讨报告 (HTML)  →  extract.py        提取元数据与牌谱
                 →  convcli           tenhou 格式 → mjai 事件流
                 →  analyze_human.py  逐决策取 q 值，识别实际动作
                 →  features.py       提取 gap12 / 合法动作数 / 巡目 / 立直状态
                 →  structure.py      分桶统计
                 →  table_gen.py      生成人类行为表
```

`human_error_model.py` 给出上述统计的可复现实现：输入 q 值向量与合法动作掩码，按人类行为表采样一个动作。

## 目录

```
analysis/    数据管道与统计脚本
convcli/     天凤格式 → mjai 的转换 CLI（基于 convlog）
results/     聚合结果（CSV/JSON，不含原始对局）
human_error_model.py   人类失误模型的可复现采样实现
PARAMETERS.md          参数含义与标定方法
docs/findings.md       完整发现与方法说明
```

## 复现

需要自备 Mortal 权重与 `libriichi`（本仓库不包含）。脚本通过环境变量或配置常量指定模型路径：

```python
MODEL_PATH = "./runtime/mortal.pth"   # 自备
DATA_DIR   = "./data"                 # 检讨报告 HTML
```

## 数据与隐私

仓库**不包含任何原始牌谱**。所有 `results/` 内容均为聚合统计量（分桶比率、分位数），无法回溯到具体玩家；段位以 Tier-N 匿名表示。
