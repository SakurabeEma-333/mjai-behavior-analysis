# 方法与发现（完整版）

## 一、问题

「AI 一致率」是麻将社区常用的指标：把一名玩家的每一手，与某个 AI 引擎的首选对比，统计相同的比例。但它常被当成"实力"或"是否作弊"的依据，而很少有人检验它到底测了什么。

本项目做了三件事：

1. 建立可信的人类基线（同期、同版本、可分层）
2. 拆解"失误"的结构，而不只看它的数量
3. 给出可复现的采样机制，反向验证上述结构

## 二、数据

| 项目 | 说明 |
|---|---|
| 样本 | 71 局高阶对局（段位 3 / 4 / 9 / 13，各 10~21 局） |
| 决策数 | 10,585 |
| 检讨口径 | Mortal 3.0，τ = 0.10，mjai-reviewer 1.5.10，全部半庄 |
| 时间 | 全部为 2026-10 同期检讨 |

参照引擎只用于给每个决策点打分，其权重不在本仓库内。

## 三、指标定义

对每个决策点：

- **一致**：实际动作 == 引擎首选（忽略赤五与吃碰的组合差异）
- **质量分**：`(q_实际 − q_min) / (q_max − q_min)`，1.0 = 打了最优手
- **gap**：`q_最优 − q_次优`，衡量这个决策"有多明确"

## 四、发现

### 4.1 一致率与段位几乎无关

| 段位 | 局数 | 合并一致率 | 组内 sd |
|---|---|---|---|
| Tier 13 | 20 | 81.63% | 2.81 |
| Tier 9 | 10 | 83.28% | 2.17 |
| Tier 4 | 21 | 80.09% | 4.27 |
| Tier 3 | 20 | 79.20% | 3.39 |

最高档与最低档差 2.1pp，但组内波动 2.2~4.3pp。**一致率的分辨率不足以区分段位。**

原因不难理解：一致率量的是"你有多接近参考引擎的打法"，而每个人的风格偏好（进攻性、防守尺度、点数意识）都会稳定地造成偏离，这些偏离不损失胜率。

### 4.2 失误率由"决策明确程度"决定

| gap 桶 | 决策数 | 失误率 |
|---|---|---|
| 0 – 0.1 | 423 | 56.7% |
| 0.1 – 0.25 | 782 | 51.3% |
| 0.25 – 0.5 | 1,013 | 48.1% |
| 0.5 – 0.9 | 1,622 | 32.7% |
| 0.9 – 1.5 | 2,396 | 14.6% |
| 1.5 – 2.5 | 3,403 | 8.5% |
| ≥ 2.5 | 4,349 | 2.7% |

这是整个项目最重要的一条：**人类在"一眼看得出"的局面里几乎不犯错，在"两可"局面里接近五五开。**

任何"固定概率撒误差"的模型都无法复现这个形状——它在明确局面会产生过多失误，在两可局面又过少。

### 4.3 失误的"成本"分布

失误的质量分分布（2,077 个失误）：

| 质量区间 | 占比 | 含义 |
|---|---|---|
| < 0.2 | 9.3% | 真正的蠢手 |
| 0.2 – 0.6 | 2.2% | 明显错 |
| 0.6 – 0.8 | 12.8% | 中等 |
| ≥ 0.8 | 73.9% | 几乎等价，只是换了张牌 |

所以人类的失误是"大量轻微偏离 + 少量深坑"。**均值 0.785，中位 0.96。**

### 4.4 深坑来自鸣牌判断

弃牌决策的失误质量集中在 0.78~0.99，几乎没有深坑；质量分 < 0.2 的失误主要出现在吃/碰/杠的取舍上。鸣牌窗口整体偏离率 10.9%。

直觉上也合理：弃牌有大量等价选择（换一张差不多的牌），而鸣牌是二元的（碰 or 不碰），判断错了就是整整一档。

### 4.5 失误不成簇

逐局失误序列的 lag-1 自相关 +0.021（i.i.d. 期望 −0.007，n=71 时标准误约 0.013）。也就是说，人类的失误在局内接近独立事件，没有明显的"走神期"。

这条推翻了一个常见假设：人们以为人会"连续犯错"，但在这种粒度的决策上并非如此。

### 4.6 局长度无影响

决策数与一致率的相关系数 r = +0.034。此前有观点认为"短局一致率偏高"，在本样本中不成立。

## 五、机制

基于 4.2 与 4.4 的形状，`human_error_model.py` 采用两层结构：

```
鸣牌窗口  → 以 10.9% 概率改选相反侧（该碰不碰 / 该过则碰）
弃牌决策  → 按 gap 查表得偏差率，偏离时从该桶的质量分位点抽样
其余      → 打最优
```

在 1,473 个决策上采样验证：

| 指标 | 本机制 | 人类实测 |
|---|---|---|
| 失误率 | 18.59% | 20.07% |
| 失误质量均值 | 0.786 | 0.785 |
| 深坑占比 | 11.5% | 11.5% |
| 近等价占比 | 74.5% | 73.9% |

四个统计量同时命中，且按 gap 分桶的结构由构造保证。

## 六、局限

1. **参照引擎不同，绝对值会漂移**：本项目的质量分基于某一份权重；换一份权重，绝对数值会变，但分布形状相对稳定。
2. **样本量**：71 局足以确定均值（±0.75pp），但不足以分辨 2pp 级别的段位差异（需每组约 39 局）。
3. **环境差异**：样本全部来自高段位对局。低段位场的对手更弱、局面更不规范，人类失误率可能不同。
4. **未建模的维度**：巡目、点数状况、听牌状态对失误率的影响尚未纳入；这些维度需要更大的样本才能稳定估计。
