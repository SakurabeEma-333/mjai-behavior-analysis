# mjai-behavior-analysis

[简体中文](README.md) | [English](README.en.md) | **日本語**

[Mortal](https://github.com/Equim-chan/Mortal) を参照エンジンとして、**人間プレイヤーの打牌一貫性**を定量的に分析し、その**ミスの構造**——「局面の明瞭さ」によってミス率がどう変わるか——を調べる研究です。

本リポジトリは計測とモデリングのみを扱います。ゲームクライアントの自動操作、自動対局、アンチチート回避の実装は含みません。

## 主な結果

高段位の 71 局（10,585 決定）での計測値：

| 指標 | 値 |
|---|---|
| 一致率（AI の第一候補と同一） | **80.4%**（局間 sd 3.67pp） |
| ミス率 | 19.62% |
| 「ほぼ等価」なミス（品質 > 0.8） | **73.9%** |
| 「深いミス」（品質 < 0.2） | 11.5% |

**1. ミス率は「局面の明瞭さ」の強い関数**

最良手と次善手の q 値差（gap）でバケット分けすると：

| gap | 決定数 | ミス率 |
|---|---|---|
| 0 ~ 0.1（どちらでもよい） | 423 | **56.7%** |
| 0.3 ~ 0.6 | 1,013 | 48.1% |
| 1.2 ~ 2.5 | 2,396 | 14.6% |
| 2.5 以上（明らか） | 4,349 | **2.7%** |

**2. 一致率と段位はほとんど無関係**

Tier 13（81.6%）、Tier 9（83.3%）、Tier 4（80.1%）、Tier 3（79.2%）の差は群内変動より小さく、統計的に有意ではありません。一致率は「参照 AI にどれだけ似ているか」を測るもので、強さではありません。

**3. 深いミスはほぼ鳴き判断に由来する**

打牌のミスは品質 0.78~0.99（ほぼ等価な牌の入れ替え）に集中し、品質 < 0.2 の深いミスはチー・ポン・カンの判断に多く現れます（鳴き判断の逸脱率 10.9%）。

**4. ミスはほぼ独立で、固まらない**

局ごとのミス系列の lag-1 自己相関は +0.021（i.i.d. 期待値 −0.007）。

**5. 局の長さは一致率に影響しない**

決定数と一致率の相関係数は r = +0.034。

## 手法

```
検討レポート (HTML)  →  extract.py        メタデータと牌譜を抽出
                     →  convcli          天鳳形式 → mjai イベント列
                     →  analyze_human.py  決定ごとの q 値と実際の打牌
                     →  features.py       gap12 / 合法手数 / 巡目 / 立直状態
                     →  structure.py      バケット別統計
                     →  table_gen.py      人間行動テーブルの生成
```

`human_error_model.py` は上記統計の再現実装です。q 値ベクトルと合法手マスクを入力として、人間行動テーブルに従って 1 手をサンプリングします。

## 構成

```
analysis/    データパイプラインと統計
convcli/     天鳳形式 → mjai 変換 CLI（convlog ベース）
results/     集計結果（CSV/JSON、生ログは含まない）
human_error_model.py   サンプリング実装
PARAMETERS.md          パラメータの意味と較正方法
docs/findings.md       詳細な知見と手法
```

## 再現方法

Mortal の重みと `libriichi` は各自で用意してください（本リポジトリには含みません）。

```python
MODEL_PATH = "./runtime/mortal.pth"   # 各自で用意
DATA_DIR   = "./data"                 # 検討レポートの HTML
```

## データとプライバシー

生の牌譜は一切含みません。`results/` の中身はすべて集計統計（バケット別比率・分位点）で、個人を特定できません。段位は Tier-N として匿名化しています。
